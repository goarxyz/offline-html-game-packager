Public JSON API

Build with the catalog.

The catalog is a static, cache-friendly JSON endpoint. No key, account, or server-side SDK is required. The hosted library uses it to download, cache, unzip, and run each game on demand.

Endpoint

GEThttps://goarxyz.github.io/offline-html-game-packager/api/catalog.json

Quick start

const response = await fetch(
  "https://goarxyz.github.io/offline-html-game-packager/api/catalog.json"
);
const catalog = await response.json();

console.log(catalog.gameCount); // 300
console.log(catalog.games[0].packageUrl);

Response

FieldTypeDescription
generatedAtISO dateTime the catalog was assembled.
releaseTagstringGitHub Release containing the packages.
gameCountnumberNumber of available games.
gamesarrayGame metadata and asset locations.

Integrity and caching

Use packageSha256 to verify a downloaded ZIP before caching it. Clients can store packages in IndexedDB and only fetch a game after the user chooses it.
